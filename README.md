# LIST MONEY By ALEX

Aplikasi Android WebView untuk LIST MONEY.

## Membuat APK di GitHub
1. Buat repository baru di GitHub.
2. Upload semua isi folder ini.
3. Pastikan branch utama bernama `main`.
4. Buka tab **Actions**.
5. Pilih **Build APK**.
6. Tekan **Run workflow**.
7. Setelah selesai, buka hasil workflow dan download artifact **LIST-MONEY-By-ALEX-APK**.
8. Ekstrak ZIP artifact lalu install `app-debug.apk` di Android.

Workflow juga otomatis berjalan setiap kali ada push ke `main`.
